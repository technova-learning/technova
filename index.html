Welcome to your first HTML lesson.

1. What is HTML?

HTML stands for HyperText Markup Language. It is used to create the basic structure of a webpage.

2. Why do we use HTML?

HTML tells the browser what content should appear on a webpage, such as headings, paragraphs, links and images.

3. What are HTML Tags?

HTML tags are special words written inside angle brackets. They tell the browser how to display the content.

Common HTML Tags

<h1> is used for the main heading.

<h2> is used for a section heading.

<p> is used for a paragraph.
